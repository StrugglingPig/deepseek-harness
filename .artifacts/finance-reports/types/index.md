## 缺口与补齐建议

| 缺口 | 缺失输入 | 可补齐的免费上游 |
|---|---|---|
| 事件背景 | 事件时间线、公告原文、事件前预期 | 已接入 Finnhub 公司新闻与 SEC 公告列表；公告原文可用 SEC EDGAR full-text（免费）与巨潮资讯（A股） |
| 供需平衡 | 库存、供需平衡表、成本曲线 | 需要新增 EIA API v2（免费 key，原油/天然气库存与产量）或交易所库存周报；FRED 已提供布伦特、天然气、铜价基准 |
| 汇率驱动 | 仓位（多空持仓） | 需要新增 CFTC Commitments of Traders（免费，每周持仓报告）；利差与汇率腿已由 FRED 提供 |
| 配置与风险预算 | 指数估值与盈利、资金流与仓位、宏观状态序列 | 宏观状态序列已接入 FRED（可并入本节评分）；指数估值与盈利需要指数 PE/EPS 数据源；资金流与仓位需要 CFTC 或 ETF 资金流源 |
